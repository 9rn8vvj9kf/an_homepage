ハムスタースロットマシーンについて
作者：内藤雅裕（ちゃんまん）氏

１．動作環境について
　　　　OS 　　 　　 Windows 95 (WINDOWS NTは未確認)
　　　　MEMORY 　　 16ＭＢ以上推奨
　　　　CPU　　 　 　DX2-486 66MHZ 以上（PENTIUM 推奨）
　　　　音源　　　　 SOUND　BLASTER（ＰＣＭ音源）が有れば音楽が楽し めます。
　　　　COLOR　　　 ２５６色以上
　　　　
　　　　必要ＤＬＬ 　VB40032.DLL 　　　　　
　　　　空き容量　 　２ＭＢのHDD
　　　　　　fileサイズ　　　　１７８ｋｂ

2.GAME 内容
対象　３歳以上１０歳までの子供用ですが、大人も楽しめます。

　A.可愛いハムスターのスロットマシーン
　B.マウスをクリックするか、キーボードを押すと絵が回転スタートします
　C.絵が合うとハムスターがこちらを振り向く
　D.楽しい音楽入り
　E.ハムスターの紹介、好物の説明有り
　F．プレイヤーの名前を入れれば絵が有った回数でベスト１０ランキング出 来る
　　　　　　
３．ダウンロードと解凍

　A.　 はむすろ（スロットマシン） と書かれた部分をクリックするとダウンロード
　　　出来ます

　Ｂ．解凍は適当なフォルダーを作製しダウンロードされた　hamusr.exe を ダブルクリック
　　　します。自動解凍されますのでこの時点でダウンロ ードされたファイルhamusr.exeは
　　　不要となりますので削除して下さい。
　
　Ｃ．解凍すると次のファイルが出てきます 

　　 1.readme.txt   説明
　　 2.hamusuro.exe はむすろ ver1.0本体　＜-------これをクリックで実行
 　　3.hamusuro.txt 100回スロットランキング用ワークファイル
 　　4.sanva3.wav   ゲーム用音声ファイル
 　　5.surot2.wav   ゲーム用音声ファイル
４．program　実行
　　hamusuro.exeをクリックするとprogramスタートします。
