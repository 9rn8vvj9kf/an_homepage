多機能カレンダー　Nycal.exe 紹介　

windows 95 対応　32Bit プログラム多目的・計算カレンダーについて
Nycal.exeの紹介
　　　　 プログラムの機能
　　　・　日本と米国の休日を計算表示、日米休日を同一カレンダー上に表示可能
　　　・　年齢計算・星占いの星座・誕生石、干支、九星、を誕生日から計算表示
　　　・　誕生日から長寿祝いを計算し表示（例　還暦）
 　 　・ 大安、先勝、仏滅等六曜計算表示 
　　　・　日米銀行休日カレンダー機能
　　　・　和暦-->西暦 西暦--->和暦変換、３月年度末の時和暦年度表示
　　　・　利息計算（電卓形式、一覧形式）
　　　・　日数計算
　　　・　応答日計算
　　　・　日別スケジュール設定・表示
 　　 ・　月間スケジュール一括表示
　　　・　海外の現在時刻を計算し表示
